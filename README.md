# Proyectosnico

Repositorio con los proyectos de Nico.

| Proyecto | Carpeta | Qué es |
| --- | --- | --- |
| HIDROTEKA | raíz (`index.html`, `product.js`, `styles.css`) | Sitio de la tienda de materiales para piscina, con carrito y contacto por WhatsApp |
| MIXDECK | [`dj-system/`](dj-system/) | Software DJ en el navegador: dos decks, mixer, análisis automático, Automix y Spotify |

Cada proyecto es estático (HTML, CSS y JavaScript) y se abre directamente en el navegador.
MIXDECK tiene su propio [README](dj-system/README.md) con instrucciones y capturas.
